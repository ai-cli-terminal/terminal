# v0.3.4

Android imported document reader metadata patch.

## What changed

- Android imported workspace documents now record content kind, file byte count,
  preview bytes read, and preview line count.
- `Open Last` keeps the app-private workspace boundary, but binary or non-UTF-8
  imports now reopen as safe metadata summaries instead of trying to render raw
  bytes in the transcript.
- Android/F-Droid version metadata is advanced to `0.3.4` / `304`.
- Project handoff, troubleshooting, history, task, and remaining-work priority
  docs now reflect the post-Relay/M2 local closeout state.

## Verification

- `gradle -p android :app:testDebugUnitTest`
- `git diff --check`
- `npm run check:release-followup` still reports expected external blockers:
  `msi`, `androidSigningSecrets`, `fdroidBuild`
- `npm run export:release-followup-evidence-packet`

## Known follow-ups

- Windows MSI evidence still requires a native Rust/MSVC/WiX packaging host.
- Android release signing still requires real GitHub repository signing secrets.
- F-Droid still requires real `fdroid build` or buildserver evidence.

Existing v0.3.3 Windows GUI assets remain the reference for the GUI packaging
smoke until the v0.3.4 release workflow uploads the new assets.
